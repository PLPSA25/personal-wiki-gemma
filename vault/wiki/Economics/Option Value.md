# Option Value

Option value arises when waiting is possible and the information that arrives is valuable. This value is often realized when the decision is at least partly irreversible, creating a one-way door for experimentation. The value of this option is tied to the potential for learning and making a decision based on new information.

## Key points

- Option value exists when waiting is possible, valuable (pivotal) information will arrive, and the action is at least partly irreversible (a one-way door). ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- Sunk costs concern a door that has already closed; irreversibility also matters looking forward. ([[raw/Economics Lectures|Economics Lectures, Lecture 2]])
- When a choice is hard to undo, keeping options open has value. ([[raw/Economics Lectures|Economics Lectures, Lecture 2]])
- Information is worth something only if it is pivotal; valuable information is pivotal, it is worth most when you are close to indifferent and when you know least. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- Information about a chance node is drawn by moving that node in front of the decision it informs; its value is the expected value of the tree with the node moved minus the tree without. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- Reordering a tree cannot create value; only acting on what you learn can. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
