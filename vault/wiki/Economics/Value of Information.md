# Value of Information

The value of information is determined by how it changes the expected value of a decision. Information is most valuable when it is pivotal, meaning it is worth most when a decision-maker is close to indifferent and knows the least. Information allows for action, as reordering a tree does not create value, but acting on what is learned does. Information can be acquired directly or indirectly through waiting and experimentation.

## Key points

- Information about a chance node is drawn by moving that node in front of the decision it informs; its value is the expected value of the tree with the node moved minus the tree without. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- valuable information is pivotal, it is worth most when you are close to indifferent and when you know least. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- Reordering a tree cannot create value; only acting on what you learn can. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- Option value exists when waiting is possible, valuable (pivotal) information will arrive, and the action is at least partly irreversible (a one-way door). ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
- Firms buy information directly (A/B tests, consultants, surveys, market data) and indirectly by waiting and experimenting. ([[raw/Economics Lectures|Economics Lectures, Lecture 9]])
