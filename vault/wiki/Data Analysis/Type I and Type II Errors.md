# Type I and Type II Errors

Type I and Type II errors occur when making decisions based on sample data, where a Type I error is rejecting a true null hypothesis, and a Type II error is failing to reject a false null hypothesis. These errors exist because there is always a risk of making the wrong decision, and the probability of each error can be calculated and managed.

## Key points

- A Type I error is rejecting a true H0 is a false positive: taking action when you should stay put ([[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 5]]; [[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 4]])
- A Type II error is retaining a false H0 is a false negative ([[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 5]]; [[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 4]])
- The significance level alpha is the maximum tolerated Type I error ([[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 5]])
- The probability of a Type II error depends on the alternative and is generally smaller when the truth is far from the null ([[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 5]])
- Wide control limits reduce Type I error (you stop only for ultra-bad outcomes) but raise Type II error ([[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 4]])
- Narrow limits reduce Type II error (you almost always stop when there is a real problem) but you stop more often for nothing ([[raw/Data and Decisions Lectures|Data and Decisions Lectures, Lecture 4]])
